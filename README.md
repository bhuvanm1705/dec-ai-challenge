# MindFlow 🧠

**MindFlow** is an AI-powered study companion designed to make learning interactive and effortless. Simply enter a topic or paste your rough notes, and MindFlow instantly transforms them into dynamic flashcards and quizzes using the power of the Groq API.

Built for the **December AI Challenge** (Grades 6-12).

## 🚀 Features
- **Smart Generation**: Converts any text or topic into study materials in seconds.
- **Flashcard Mode**: Interactive flip cards with smooth animations (Framer Motion).
- **Quiz Mode**: Multiple-choice questions with instant scoring and confetti celebration!
- **Modern UI**: A clean, premium aesthetic built with React and Tailwind CSS v4.

## 🛠️ Tech Stack
- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS v4
- **AI Engine**: Groq API (Llama 3.3 model)
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Installation
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/mindflow.git
    cd mindflow
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run locally:**
    ```bash
    npm run dev
    ```

4.  **Open in browser:**
    Navigate to `http://localhost:5173`.

## 🔑 Usage
1.  Get a free API Key from [Groq Cloud](https://console.groq.com/).
2.  Paste the key into the app (it's saved locally for convenience).
3.  Enter a topic (e.g., "The Water Cycle" or "Newton's Laws").
4.  Choose **Flashcards** or **Quiz** to start learning!
