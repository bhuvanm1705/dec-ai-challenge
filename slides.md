# MindFlow
## Study Smarter, Not Harder 🎓

Transforming Notes into Knowledge with AI

**Challenge Submission for December AI Challenge**

---

## 1. The Problem: Studying is Broken 📉

- **Passive Learning:** Reading notes repeatedly has low retention.
- **Time Consuming:** Students spend 80% of time *making* flashcards, only 20% *studying*.
- **Boring:** Textbooks lack engagement and gamification.
- **Manual Labor:** Creating quality mnemonics or quizzes manually is difficult and slow.

---

## 2. The Solution: Enter MindFlow 🚀

**An AI-Powered Study Companion that transforms any topic into active learning modes instantly.**

- **⚡ Instant Flashcards:** Auto-generated key concepts with "Flip" animations.
- **🎮 Gamified Quizzes:** Test knowledge with instant feedback & confetti rewards.
- **🎓 Memory Hacks:** AI generates strict rhymes & acronyms for complex lists.
- **🗣️ Audio Learning:** Built-in Text-to-Speech for auditory learners.

---

## 3. How It Works (The "Flow") 🌊

1.  **Input:** User enters a topic (e.g., "Photosynthesis") or pastes notes.
2.  **AI Processing:** 
    - **Groq API** (Llama 3 70b) analyzes text.
    - Generates 3 structured JSON datasets (Flashcards, Quiz, Mnemonics).
3.  **Output:** 
    - React renders rich, interactive components.
    - User engages with content immediately.

---

## 4. Technology Stack 🛠️

- **Frontend:** React + Vite (Lightning fast performance)
- **Styling:** Tailwind CSS (Glassmorphism & Mobile Responsive)
- **AI Engine:** Groq API (Sub-second inference speeds)
- **Animations:** Framer Motion (Smooth transitions)
- **Deployment:** Vercel / GitHub Pages
