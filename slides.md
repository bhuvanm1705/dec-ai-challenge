## Slide 3: The Solution
**Headline:** Enter MindFlow 🧠
**Points:**
- **Instant Creation:** Paste notes -> Get Flashcards & Quizzes in < 2 seconds.
- **Active Recall:** Interactive study modes powered by Groq AI.
- **Gamified:** Validates learning with quizzes and rewards.
**Visual:** "Input -> Magic -> Studying" flow diagram.

---

## Slide 4: Under the Hood (Architecture)
**Headline:** Built with Modern Tech
**Stack:**
- **Frontend:** React + Vite (Fast & Responsive)
- **Styling:** Tailwind CSS v4 (Glassmorphism & Gradients)
- **AI Brain:** Groq API running Llama 3.3-70b (Blazing fast inference)
- **Animation:** Framer Motion
**Visual:** Simple architecture diagram connecting User -> React App -> Groq API.
